# 工作计划

本机用的任务清单。任务写在你自己的笔记文件夹里，不上传。打开就是一个小窗口，不用安装 Python。

可以按今天、明天、最近七天看任务，改日期、时间和循环，也可以把一段时间记到时间书，或记回本地笔记。

## 怎么打开

1. 下载 [最新的工作计划.zip](https://github.com/lingyunlovelyf-bot/work-plan/releases/latest)。
2. 解压。
3. 双击「打开工作计划.bat」。

第一次打开后，进设置，选择自己的笔记文件夹。文件名里要带设置中的词（一开始是「接下来规划」）才会收进来，这个词可以改。

浏览器默认是 Edge，会开成单独的小窗口。设置里可以改成 Chrome、系统默认浏览器，或填写别的 exe 路径。改完后，下次打开窗口才换浏览器。

## 时间书

设置里自己填时间书的地址和令牌。令牌写在这台电脑的 `timebook.local.json`，不会打进压缩包，更新时也不会被盖掉。

不想用时间书时，可以把记录改成记回本地笔记。

## 自动更新

程序打开几秒后，会看这个仓库的最新 Release。版本比现在新，就下载 `工作计划.zip`，换掉程序文件，然后自己重新打开。

这些会留下，不会被更新盖掉：

- 笔记文件夹、浏览器和其他设置（`settings.json`）
- 时间书地址和令牌（`timebook.local.json`）
- 已经拉下来的时间书名录（`timebook-cache.json`）

## 发布一个新版本

1. 把 `update.json` 里的 `version` 加大，例如 `1.0.1`。`repo` 是 GitHub 仓库，写成 `用户名/仓库名`。
2. 在项目目录运行 `python pack.py`，得到 `dist/工作计划.zip`。
3. 在 GitHub 仓库的 Releases 里新建一个标签，名字和版本对应，例如 `v1.0.1`。
4. 把 `工作计划.zip` 传上去。文件名要保持 `工作计划.zip`。

已经装过的人下次打开时，会自己换到这个版本。
