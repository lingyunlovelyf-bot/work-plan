同步服务

填了地址、令牌和库名之后，任务以 Fast Note Sync 为准。写入前会再对一次版本，对不上就不写，并改用服务器上的新内容。连不上时只显示上次拿到的，不会写回去。本地文件夹只在没填同步时使用。

笔记文件夹

选一个文件夹。文件名里带下面这些词的笔记才会收进来。换完保存，马上按新的读。

打开用的浏览器

Edge 和 Chrome 会开成单独的小窗口。系统默认是普通网页。也可以填别的 exe 路径。下次打开窗口时生效。

空间

编辑

Alt+回车写出补充，再按一次先告一段落。补充里回车换行。结束会勾掉这条任务。

搜任务

搜今天的任务。点一条就加进自由，然后回到输入。

自由

一行一段：时间，分类，备注。分类可以写名字或关键词，优化归到测试优化，洗杯子归到杂。1100 就是 11:00。3分钟、+3、3m、1h、1小时、一小时都是从上一段再加。单独的数字记成支出，28 是 28 元，27.8 是 27.8 元，备注里照原样留下。现在表示到此刻。回车换行，Alt+回车发送。# 搜任务。

全页编辑

回车会再起一行，并带上同样的 - [ ]。Tab 往里一级，Shift+Tab 往外一级。Ctrl+回车写上。
